
# 🤖 Autonomous Rover with Robotic Arm for Color-Based Sorting

## 📌 Project Overview

The **Autonomous Rover with Robotic Arm for Color-Based Sorting** is a collaborative college mini project focused on designing and developing an intelligent robotic system capable of identifying and sorting objects based on color.

The system integrates **autonomous mobility**, **sensor-based color detection**, and a **robotic manipulator** to perform real-time pick-and-place operations. This project demonstrates practical applications of **robotics, automation, and embedded systems** in real-world environments.

---

## 🎯 Objectives

* Design an autonomous rover capable of stable navigation
* Detect object colors accurately using sensors
* Pick and place objects using a robotic arm based on detected color
* Demonstrate sensor-driven decision making in real time
* Reduce manual intervention in sorting processes

---

## 🛠️ System Features

* 🚗 **Autonomous Rover** with differential drive
* 🦾 **4-DOF Robotic Arm** for precise pick-and-place operations
* 🎨 **Color Detection System** for accurate classification
* 🔄 **Real-Time Sorting** based on predefined color rules
* 📡 **Microcontroller-based Control** with sensor integration

---

## 🧩 Components Used

* Arduino Mega / ESP8266
* RGB Color Sensor
* Servo Motors & DC Motors
* Motor Driver (L298N)
* IR Sensors
* Robotic Arm with Gripper
* Rover Chassis & Wheels
* Conveyor mechanism (if applicable)

---

## ⚙️ Working Principle

1. The rover navigates autonomously within the workspace.
2. Objects are detected and scanned using a color sensor.
3. The detected color is processed by the microcontroller.
4. The robotic arm picks the object and places it into the designated bin based on its color.
5. The process repeats continuously in real time.

---

## 📊 Results

* Color detection accuracy: **~85%**
* Sorting efficiency: **~82%** under controlled conditions
* Successful real-time coordination between sensors, rover, and robotic arm
